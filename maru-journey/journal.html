🦭 まるのアザラシめぐり

国内のアザラシのいる施設、ぜんぶで60か所。伊勢シーパラダイスから始めて、列車を乗り継ぎ、ご当地のものを食べて、その土地のお土産を買って、最後は大阪・海遊館へ。見ている人も一緒に旅した気分になれるような、毎日の記録です。

訪問: 4 / 60 施設 累計支出: 77,840円 現在地: 半田市（カンデオホテルズ半田に宿泊中）
旅程　伊勢・鳥羽 → 名古屋・豊橋 → 静岡・伊豆 → 関東 → 東北 → 北海道 → 日本海側・北陸 → （空路）鹿児島 → 九州 → 中国 → 四国 → 関西 → ゴール: 海遊館。毎朝7時スタート、移動は電車優先で時刻表どおり、毎晩ホテル泊。天気と運休は当日の情報で確認して、悪天候の日は行程を変えます。
